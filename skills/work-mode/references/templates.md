# 可選的短模板

將資訊放入既有 issue、任務記錄或 PR 即可，不強制多建立檔案，也不維護多份相同內容。

## 任務契約

```markdown
目的與交付：
完成條件：
- AC1：
- AC2：
不變條件／範圍：
重要假設或待決事項：
步驟與狀態：
```

## 驗證證據

```markdown
Revision／環境：
受測內容：是否含未提交修改、對應 patch／變更紀錄；與最終 PR commit 的核對結果

| 完成條件 | 命令或操作／輸入 | 預期 | 實測與證據 | 狀態 |
|---|---|---|---|---|
| AC1 | | | | PASS／FAIL／BLOCKED |

必要案例：實際選取／執行／跳過摘要與原因（可連既有測試報告）
必要 CI：run URL、source commit、可取得的 target／實際受測提交、目前 policy 結果／尚缺什麼
跳過與限制：
```

## PR 正文

```markdown
這項變更解決什麼問題、現在會怎麼運作：
主要設計與改動：
驗證：本機與 CI 分開摘要，連到證據與適用 revision
風險／尚未驗證／相依 PR：
人類審核重點：
```

## 交接或恢復

```markdown
任務／契約連結（含完成條件與待決事項）：
目前 branch／revision／工作目錄及未提交修改：
PR／待完成 CI run 連結與目前狀態：
已完成／證據位置：
未完成與阻擋：
下一個具體動作：
```
