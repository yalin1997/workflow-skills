# 可選的短模板

將資訊放入既有 issue、任務記錄或 PR 即可，不強制多建立檔案，也不維護多份相同內容。

## 任務契約

```markdown
目的與交付：
完成條件：
- AC1：
- AC2：
不變條件／範圍：
重要假設或待決事項：
步驟與狀態：
```

## 驗證證據

```markdown
Revision／環境：
| 完成條件 | 命令或操作／輸入 | 預期 | 實測與證據 | 狀態 |
|---|---|---|---|---|
| AC1 | | | | PASS／FAIL／BLOCKED |
必要 CI：run URL、驗證的 commit、結果／尚缺什麼
跳過與限制：
```

## PR 正文

```markdown
這項變更解決什麼問題、現在會怎麼運作：
主要設計與改動：
驗證：本機與 CI 分開摘要，連到證據與適用 revision
風險／尚未驗證／相依 PR：
人類審核重點：
```

## 交接或恢復

```markdown
目前 revision／工作目錄：
已完成／證據位置：
未完成與阻擋：
下一個具體動作：
```
